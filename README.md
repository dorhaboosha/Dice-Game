# Dice Game 🎲

A simple browser-based dice game for 2 players. Refresh the page to roll the dice — the higher number wins.

## Live Demo
- https://dorhaboosha.github.io/Dice-Game/

## How to Play
1. Open the game in your browser.
2. Refresh the page (or reload) to roll both dice.
3. The title shows who won (Player 1 / Player 2 / Draw).

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)

## Run Locally
No installation needed:
1. Clone the repo:
   ```bash
   git clone https://github.com/dorhaboosha/Dice-Game.git
   ```
2. Open `index.html` in your browser.

## Project Structure
- `index.html` – page layout
- `styles.css` – styling
- `index.js` – dice logic
- `images/` – dice images/assets
